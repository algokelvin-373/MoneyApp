MoneyLife

Kebijakan Privasi

Terakhir diperbarui: 16 November 2026

MoneyLife menghormati privasi Anda. Kebijakan ini menjelaskan data yang diproses aplikasi MoneyLife versi 1.0.0 dan cara Anda mengendalikannya. Kebijakan ini berlaku untuk aplikasi dengan package com.kelvinht.moneylife.

Data yang diproses

MoneyLife memproses catatan pengeluaran, nominal, kategori, tanggal, catatan opsional, dan saldo tabungan yang Anda masukkan. Seluruh data tersebut disimpan hanya di database lokal pada perangkat Anda.

Pengumpulan dan pembagian data

MoneyLife tidak membuat akun, tidak memiliki izin internet, tidak memakai iklan atau analitik, serta tidak mengirim, mengumpulkan, menjual, atau membagikan data Anda kepada pengembang maupun pihak ketiga.

Penyimpanan dan penghapusan

Data disimpan sampai Anda menghapus transaksi atau menghapus instalasi aplikasi. Menghapus instalasi akan menghapus seluruh data MoneyLife. Backup otomatis dinonaktifkan, sehingga data tidak dipulihkan otomatis setelah aplikasi dihapus.

Keamanan

Data dilindungi oleh sandbox aplikasi Android. Jaga keamanan perangkat, PIN, dan akun sistem operasi Anda. MoneyLife tidak menyediakan sinkronisasi cloud atau pemulihan data pada versi ini.

Anak-anak

MoneyLife tidak ditujukan khusus untuk anak-anak dan tidak mengumpulkan data pribadi anak maupun pengguna lain.

Perubahan kebijakan

Jika perilaku data aplikasi berubah, kebijakan ini dan deklarasi Data Safety akan diperbarui sebelum versi baru dirilis.

Kontak

Untuk pertanyaan privasi, hubungi pengembang melalui github.com/algokelvin-373.
